# Map data

`route-waypoints.json` and the derived street geometries in `public/map-routes/`
contain information from OpenStreetMap, made available under the
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

© OpenStreetMap contributors. Source: https://www.openstreetmap.org/copyright

OSM reference data retrieved on 2026-11-24 using Overpass API. Each located
reference links to its originating OSM element. Derived street paths were
generated with OSRM on the FOSSGIS public routing service; attribution and
generation timestamps are included in each JSON file. These files are provided
in editable form. Approximate reference matching is not certification of a
university route or an authorized boarding stop.
